## Skills represented

- **Network security:** Layer 2 attack analysis, Wireshark observations, port security, DHCP snooping, and dynamic ARP inspection.
- **Routing:** multi-area OSPF, BGP, EIGRP, IS-IS, route redistribution, IPv4/IPv6 addressing, and command-line troubleshooting.
- **Cloud infrastructure:** IAM policies, VPC segmentation, EC2 operations, EBS, RDS, load balancing, Auto Scaling, and CloudWatch.
- **Local AI:** Ollama, Docker Desktop, PowerShell, WSL, and browser-interface setup.

## About these reports

These reports describe academic lab work, including collaboration and troubleshooting. They are records of the original exercises; the configurations and external services were not rerun during portfolio editing. Corrected networking and local AI reference configurations are included in [examples](examples/README.md). The [technical correction notes](maintenance/TECHNICAL-REVIEW.md) explain the changes and validation scope.

PDF files are intended for reading and sharing. Word files remain editable. The [original reports](archive/README.md) are preserved without content changes; decorative covers and the OSPF class sign-off page are retained only in those originals.
